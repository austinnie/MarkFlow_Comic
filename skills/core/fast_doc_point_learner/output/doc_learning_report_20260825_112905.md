## 整体摘要

这份文档是关于FOTA自动化工具的详细使用说明书，适用于Windows 10/11 (64位)平台。该工具主要用于批量处理夏普AQUOS等日系Android手机在进行FOTA测试前的初始化工作，支持多设备同时连接并行处理，以提高产线和测试线效率。

文档结构包括工具简介、目录结构、启动方式、首次使用前准备、配置说明、使用流程、自动化流程详解、界面功能说明、日志位置、常见问题排查（FAQ）、移植到其他电脑注意事项和技术参数等内容。其中特别强调了正确的启动方式是双击“启动.bat”文件，以确保程序能够正确识别和调用ADB工具。

该工具的目录结构包含主程序FOTA-AutoTool.exe、启动脚本启动.bat、配置文件config.json以及内置的ADB工具集（adb\）。文档还提供了详细的使用说明、常见问题解决方案，并提醒用户在移植到其他电脑时需要重新配置相关设置。
